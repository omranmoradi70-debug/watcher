# watcher — سیگنال ارز دیجیتال

یک ربات تلگرام رایگان و یک اپ وب برای تحلیل چندتایم‌فریمی ارزهای دیجیتال. این پروژه برای **یادگیری و آزمایش** ساخته شده است.

## ⚠️ هشدار
این ابزار آموزشی و آزمایشی است و **توصیه‌ی مالی نیست**. معامله‌ی ارز دیجیتال ریسک ضرر دارد و هیچ سودی تضمین نمی‌شود. بازپخش تاریخی ربات هنوز لبه‌ی آماری ثابت‌شده‌ای نشان نداده است. فقط با پولی کار کن که از دست دادنش برایت مشکل نیست، و همیشه حد ضرر بگذار.
